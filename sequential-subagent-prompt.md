Use these subagents:

- product-designer
- frontend-coder
- tester
- reviewer

Build a small Flashcard Quiz App.

MVP requirements:
- add flashcards
- quiz one card at a time
- reveal answer
- mark correct / incorrect
- show score

Keep it beginner-friendly and small.

Work sequentially:

1. product-designer defines the MVP.
2. frontend-coder implements it.
3. tester checks the core behavior.
4. reviewer reviews the result.

Let frontend-coder choose a simple file structure.

Do not run repair loops in this workflow.

At the end, summarize:
- product design summary
- final app behavior
- file structure
- test result
- reviewer verdict
- whether the app is ready or needs another iteration
