Build a small Flashcard Quiz App.

MVP requirements:
- add flashcards
- quiz one card at a time
- reveal answer
- mark correct / incorrect
- show score

Keep it beginner-friendly and small.

Work sequentially:

1. Product Designer creates the product design.
2. Frontend Coder implements the MVP.
3. Tester tests the core quiz logic.
4. Reviewer reviews the final result.

Let the Frontend Coder choose a simple file structure.

Validation:
- If tests fail, return to the Frontend Coder for a minimal fix.
- If the Reviewer finds must-fix issues, return to the Frontend Coder.
- Keep repair cycles bounded and avoid adding new features.

At the end, summarize:
- final app behavior
- file structure
- test result
- reviewer verdict
- how to run it
